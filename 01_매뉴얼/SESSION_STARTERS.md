## 1. 단건 추출 (기본·권장) ⭐

```
02_papers/<파일명>.pdf 논문을
cpg-data-extraction 스킬 v3.0으로 추출해줘.

6단계(채팅 출력 → 연구자 확인)까지 먼저 진행하고,
내가 OK하면 scripts/save_extract.py로 저장해.
```

**언제 쓰나**:
- 처음 몇 편
- 복잡한 논문 (다군, 다중 아웃컴, 한약 처방 복잡)
- 혼자 차분히 할 때

**Claude가 할 동작**:
1. PDF 읽기
2. 데이터 추출
3. 채팅창에 5개 블록(서지/연구특성/중재/아웃컴/불확실항목) 출력 + ⚠️ 플래그
4. 사용자 OK 기다림
5. JSON 임시파일 생성 → save_extract.py 호출 → 저장
6. 완료 보고

## 2. 병렬 추출 (전략 A·속도 우선)

```
02_papers/에서 <N>~<M>번 논문(<총편수>편)을 cpg-data-extraction 스킬 v3.0으로
병렬 추출해줘.

규칙:
- 서브에이전트 1명 = PDF 1편 (절대 묶지 마)
- 각 서브에이전트는 프롬프트에 PDF 파일명 앞 숫자를 재확인하고 시작
- 추출 결과는 scripts/save_extract.py로 개별 저장
- 메인 세션에는 "완료/실패 상태 + 파일 경로"만 반환 (데이터 값 반환 금지)
- 전편 다 끝나면 ⚠️ 의심 항목만 모아서 한꺼번에 보고

병렬 처리 중 사용자 검토는 엑셀 파일을 직접 열어서 할 거야.
채팅 요약에만 의존하지 말고 엑셀로 저장까지 꼭 완료해줘.
```

**언제 쓰나**:
- 하루 10~15편 내려고 할 때
- 비슷한 품질의 RCT 여러 편 연속 처리

**처음엔 3편부터**: 감 잡고 5편 → 10편으로 단계 확장

**주의**: 절대 "10편 한 서브에이전트에게" 금지 — 혼입 위험 (7규칙 참조)

## 4. 병합 (하루 끝·마스터 통합)

```
오늘 추출한 파일들을 merge-skill로
master_심상송.xlsx (또는 AF_CPG_data_extraction_심상송.xlsx)에 병합해줘.

- 90_Output/extracts/의 AF_extract_*.xlsx 전부 스캔
- 미리보기 보여주고 내 승인받은 뒤 진행
- 번호 오름차순 정렬 삽입
- 백업·로그 생성
```

**언제 쓰나**:
- 매일 저녁 (권장)
- 5~10편 모였을 때

**마스터 파일이 Excel에 열려있으면 merge-skill이 거부**합니다. 먼저 닫으세요.

## 5. 문제 해결

### 5-1. 저장 실패

```
방금 추출한 논문의 임시 JSON이 99_Scratch/_tmp_*.json에 남아있어.
save_extract.py가 왜 거부했는지 확인하고 고쳐줘.
```

### 5-2. 재추출 (기존 파일 덮어씀)

```
90_Output/extracts/AF_extract_<번호>_<id>.xlsx를 재추출하고 싶어.
기존 파일은 99_Scratch/overwrite_backup/에 백업한 뒤,
02_papers/<파일>에서 cpg-data-extraction v3.0으로 새로 뽑아줘.
```

### 5-3. 서식만 마이그레이션 (v2.x 파일 받은 경우)

```
90_Output/extracts/ 폴더의 v2.x 파일들을 v3.0 서식으로 일괄 마이그레이션해줘.
migrate_format.py 사용. dry-run 먼저 보여주고 승인받은 뒤 실행.
```

### 5-4. 추출 결과가 이상할 때

```
방금 추출한 결과 의심되는 부분 있어.
- <논문 번호>의 <필드>가 <의심 내용>
- PDF 원문 해당 부분 다시 확인해서 정정해줘.
재저장은 수정 확인 후.
```

## 절대 하지 말아야 할 것 🚫

1. **"검증 없이 바로 저장"** — 6단계 사용자 확인은 메타분석 품질의 핵심
2. **"여러 논문 한 서브에이전트에 몰아넣기"** — 데이터 혼입 위험
3. **마스터 엑셀을 Excel에서 연 채로 merge 실행** — 락 파일 때문에 거부됨
4. **sample_v2.4.xlsx 직접 수정** — 스크립트가 매번 이 파일을 복사하므로 원본 손상 금지
5. **scripts/*.py 수정** — 스킬 업데이트 시에만, 단독으로 건드리지 말 것
6. **90_Output/extracts/의 `.bak.xlsx` 삭제** — 마이그레이션 복구용
7. **OneDrive 동기화 중에 저장 시도** — 락 충돌 가능, 잠시 기다린 뒤 시도

## 혼입 방지 7규칙 (병렬 추출 시 필수)

| # | 규칙 |
|---|---|
| 1 | 서브에이전트 1명 = PDF 1편 (예외 없음) |
| 2 | 서브에이전트 프롬프트에 번호·파일명 명시 |

| 5 | 사용자 검토 시 엑셀 파일 직접 열기 (채팅 요약 의존 금지) |
| 6 | merge 시 번호/study_id 일치 검증 (스킬 내장) |
| 7 | 동시 서브에이전트 수 상한 = 10 |
