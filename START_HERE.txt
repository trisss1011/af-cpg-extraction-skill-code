사용 환경

  - Claude Code (CLI) — 터미널에서 `claude` 명령으로 실행
  - Python 3.8 이상 + openpyxl 3.0 이상 (저장 스크립트 의존)
  - Windows / macOS 둘 다 동작 (매뉴얼은 Windows 기준 안내)

v3.2 주요 변경 (2026-05-19)

  - study_design 분류 개정: 随机/随机分为/randomized 표현만 있어도 RCT
  - 기본정보 신규 AU열 analysis_set (ITT/PP/NR, 47→48열)
  - af_type_other 코드 5 (AF with RVR) 기준 엄격화 (HR≥110 명시 시만)
  - HRV 및 파생 지표(SDNN/RMSSD/LF/HF/DC/AC 등) 아웃컴 완전 제외
  - SAE 통합 추출 (AE total과 동일 방식)
  - comorbidity 코드 6 (高栓塞·高出血) 백포트
  - merge-skill v1.1 → v2.6 (서식 보존 알고리즘 통합)
